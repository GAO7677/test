## 2026-10-13｜此前改动汇总

### 1. Linux 适配与独立运行

- 从归档项目建立 `data-platform3-linux` 副本，保留原 Windows 工程。
- 适配文件路径、配置、Linux 依赖和前台启动脚本；保留 MySQL，运行数据与模型放在数据盘。
- Web 与训练环境分离；配置支持独立验收库和运行目录，避免测试数据进入生产库。
- 修复原始数据 ID 与预处理数据集 ID 混用导致标注寻址错误。
- 验证：依赖导入、pip check、前端生产构建、独立 MySQL 的登录与基础接口通过。

### 2. 少样本训练、生成与标注

- 新增少样本页面、任务 API、`fewshot_jobs` 表及迁移；用户按组上传图像，每组填写共用训练文本和生成数量。
- 接入 BeyondObjects + FLUX.2 Klein Base 4B、BeyondObjects + SD2.1、ChimeraLoRA + SD2.1；页面联动方法与模型，拒绝无效组合。
- BeyondObjects 多组共同训练一个 LoRA；Chimera 保留共享 A、多 B 头及原生融合方式，页面说明区别。
- caption 框改为“训练文本提示词（caption）”；校验图片格式、大小、像素数、重复内容与生成数量。
- 生成结果登记为 AIGC，全部执行 COCO 80 类目标框自动标注，再进入人工修正；各次处理形成独立版本，可打包下载。
- 支持完成 LoRA 的复用生成、分阶段重试、素材和生成结果预览、来源与哈希记录。
- 队列在独立 tmux 中运行；正式训练在线记录 W&B 配置、进度和指标，不上传权重；Web 重启不终止训练。
- 验证：FLUX 两组素材的 2 步 smoke、生成、复用、真实 CPU 自动标注、人工修正和 ZIP 下载通过；本次 smoke 权重验收后按规则清理，日志与报告保留。
- 限制：COCO 框不覆盖自定义类别；零检测和自动框均需人工核验。Chimera 中途恢复不支持，完整多头权重可复用。

### 3. SSH 118 与 GPU 7

- 正式应用迁至 SSH 118 的 `/mnt/data/gaoya/agent-data/apps/data-platform3-linux`，关联该机已有数据、训练环境和权重。
- 训练使用物理 GPU 7 的 UUID，允许与既有任务共享；Web 与 COCO 检测使用 CPU，不使用 GPU 4。
- 根据方法设置启动显存门槛，连续采样，并在各 GPU 阶段与初始化前复查；不足时继续排队。
- 修复子进程错误只显示 `CalledProcessError` 的问题，保留并展示 CUDA OOM 等具体根因。
- 用户失败任务保留，由页面手动重试；不自动重启失败训练、不覆盖旧运行目录。
- 验证：26 项 CPU 回归、三个方法配置及模块导入、模型联动和多头提示通过；这些检查未额外启动三种方法的正式训练。
- 限制：共享显存检查不能锁定其他项目的占用，运行中仍可能 OOM。

### 4. 本地素材与类别展示

- 少样本组增加本地素材选择器，支持缩略图、分页、搜索、类别筛选、跨库选择、移除，与上传图像混用。

- 使用素材白名单与元数据索引，记录来源和哈希；页面选图不启动训练，创建任务后才复制所选素材。
- 验证：类别/文本索引、分页、缩略图、权限、混合选图、重复拒绝及浏览器流程通过。

### 5. 现有数据集接入与功能展示

- 测试预览、可视化、自动/人工标注、清洗、转换、采样、工作流、集成、质量评估、版本发布、血缘和下载。
- 修复版本计数误含标注/清单、类别与下载漏读部分标注结构、ZIP 混入清单、初始版本未继承标注、软删除缺少导入等问题。

### 6. 数据下载 → AIGC 补充 → 预处理与版本交付

- 查询保存条件、需求数量、用户和命中图像候选；“AIGC 生成补足”带入少样本页，不直接提交训练。

- 未完成或失败版本禁止下载、发布及作为处理输入；人工标注限制到当前版本实际存在的文件。
- 验证：43 项隔离 CPU 接口、14 项浏览器检查、方法与元数据回归、历史表迁移通过。上游生成批次采用模拟输入，导入、自动标注、人工修正和下载执行真实代码；没有追加 GPU 训练。
