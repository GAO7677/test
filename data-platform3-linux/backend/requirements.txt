# 数据中台后端依赖（Windows x64 离线环境，支持 Python 3.8.8 / 3.10 / 3.14）
# 版本选取原则：
#   - 按 python_version 环境标记分组锁定，pip 会自动选用当前解释器对应的一组；
#   - 3.8 组取各库最后一个支持 3.8 的稳定版；3.10/3.14 组取当前稳定版；
#   - opencv 为 cp37-abi3 轮子，三个版本通用；
#   - numpy 2.5 起不再提供 cp310 轮子，故 3.10 单独锁 2.2.6；
#   - numba（librosa 传递依赖）尚不支持 numpy 2.5，故 3.11+ 组锁 2.4.6；
#   - onnxruntime 为检测推理后端（v2.2 起优先于 cv2.dnn）；
#   - 全部依赖已验证存在对应平台的 Windows x64 离线 wheel（共 53 / 16 / 16 个）。
# PyInstaller 6.x 在 3.8 上可用，3.10/3.14 用最新版即可。
